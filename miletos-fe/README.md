# Miletos Frontend

Miletos frontend dashboard.

## Stack

- Next.js
- TypeScript
- App Router
- Plain CSS
- BEM naming
- Axios
- TanStack React Query
- No Tailwind CSS
- No component library

## Rules

- Do not use Tailwind CSS.
- Do not use UI component libraries.
- Build shared UI components manually.
- Use BEM class naming.
- Use Axios for HTTP calls.
- Use TanStack React Query for client-side server state.
- Keep UI-only state out of backend request bodies.
- Do not send fields like `isDashboard` to backend APIs.

## Local Commands

npm run dev
npm run build
npm run lint

Remote repository is intentionally not configured.
